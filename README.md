## Project: TrackMySpend (Student Expense Tracker)

A simple web application built with **HTML**, **CSS (Grid)**, and **JavaScript** to help students track their daily expenses.

### Features
- **Set Starting Balance:** Enter your available money and track it live.
- **Add Expenses:** Log expense name, amount (₹), and category (`Food`, `Travel`, `Books`, `Miscellaneous`).
- **Auto-Calculate:** Automatically updates **Total Spent** and **Remaining Balance** (turns green when positive, red if over budget).
